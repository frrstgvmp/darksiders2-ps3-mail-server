# Contributing

**English** · [Русский](CONTRIBUTING.ru.md)

Python 3.10+ and `python3-cryptography` are required.

```bash
python3 -m unittest discover -s tests -v
```

Preserve pinned ticket verification, expiry checks, signed profile identity,
mailbox access rules, quotas and atomic transactions. Use synthetic tickets
and temporary databases in automated tests.

For OFW reports record disc ID, game update, exact firmware, unmodified client
and certificate store, date/time, server version and the result of each action.
Record inventory receipt separately from downloading/removing a cloud key.
A fresh trophy check requires a profile without the trophy.

Do not submit PSN tickets, private keys, credentials, player databases, game
executables or assets. Keep English/Russian documentation synchronized.
PSNProfiles approval may only be stated after moderator approval.
