# Участие в разработке

[English](CONTRIBUTING.md) · **Русский**

Требуются Python 3.10+ и `python3-cryptography`.

```bash
python3 -m unittest discover -s tests -v
```

Сохраняйте закреплённый ключ проверки билетов, проверки срока и подписанной
личности, права ящиков, квоты и атомарность транзакций. Автотесты используют
искусственные билеты и временные базы.

В отчёте OFW укажите код диска, обновление игры, точную прошивку, неизменность
клиента/хранилища сертификатов, время, версию сервера и результат каждого
действия. Получение в инвентарь фиксируется отдельно от загрузки/удаления
облачного ключа. Для нового трофея нужен профиль без него.

Не прикладывайте билеты PSN, ключи, пароли, базы игроков, игровые бинарники
и ресурсы. Согласовывайте русскую и английскую документацию.
Одобрение PSNProfiles указывается только после решения модераторов.
