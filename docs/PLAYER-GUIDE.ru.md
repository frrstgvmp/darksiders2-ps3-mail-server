# Подключение игрока

[English](PLAYER-GUIDE.md) · **Русский**

IPv4 сервера: **193.232.178.202**. Обновлено: 15 октября 2026 года.
[Совместимость OFW](COMPATIBILITY.ru.md).

1. Сохраните IP, маску и рабочий шлюз.
2. Укажите основной и дополнительный DNS: `193.232.178.202`.
3. Прокси не требуется. Войдите в PSN и перезапустите игру.
4. Откройте сетевую почту в Фолианте.

Оба игрока должны использовать этот сервер. Посторонний дополнительный DNS
может вернуть адрес прежней службы. Оба DNS должны совпадать.

Для отправки выберите получателя, предмет и выполните **«Добавить предмет
к подарку»**. Проверьте вложение перед отправкой. Текст необязателен.
После успешной отправки предмет должен исчезнуть из инвентаря отправителя.

Для получения проверьте сетевую почту, выберите письмо и нажмите **«Взять всё»**
либо заберите отдельное вложение. Проверьте инвентарь. Письмо без вложения может
показывать только «Удалить». После получения предмета текст письма может остаться.

Перед выходом сохраните игру и дождитесь завершения записи. Загруженные письма
хранятся также локально; удаление без сохранения может восстановить прежнее
состояние при следующей загрузке. Автосохранение после каждого почтового
действия не установлено.

Для новой проверки Pay It Forward нужен профиль без этого трофея. Запишите
точную прошивку, код диска и обновление игры. Трофей обрабатывает сама игра;
сервер возвращает ответы почтового API.

При ошибке сообщите оператору текст и время. Не публикуйте билеты PSN и пароли.
Если PSN зависит от существующего VPN-маршрута, сохраните его.
