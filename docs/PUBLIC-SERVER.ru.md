# Публичный сервер и авторизованный доступ к почте

[English](PUBLIC-SERVER.md) · **Русский** · [Главная](../README.ru.md)

## Режимы

`public_mode:true` принимает все исходные IPv4 без регистрации. Для каждого
cloud-запроса нужен действующий подписанный PSN-билет. `allowed_clients`
не влияет на допуск, но может оставаться для отката. `capture_raw:true`
запрещён. Возьмите [публичный пример](../deployment/config.public.example.json),
замените адреса и укажите локальные TLS-файлы.

Закрытый режим (`public_mode:false`) требует непустой список IPv4.
`verify_psn_tickets:true` сохраняет те же авторизацию и права. Значение false —
старый режим локального исследования, его нельзя открывать в интернет.
Экспортёр принимает `--public` либо повторяемые `--client` для закрытого режима.
При обновлении активная конфигурация сохраняется: проверьте `config.json.new`,
не считайте, что установка сама переключила режим.

## Личность и происхождение публичного ключа

Независимый проверяющий модуль Python реализует опубликованные
[формат NP-билета и описание ECDSA-подписи](https://github.com/LBPUnion/ProjectLighthouse/blob/main/Documentation/Tickets.md):
secp192r1 и SHA-1. Это параметры исходного протокола, а не новые выбранные
проектом алгоритмы авторизации.

Закреплённая точка проверки в `assets/psn-darksiders2-key.json` восстановлена
офлайн по трём независимо выданным билетам аккаунта оператора. Все три дали
одинаковую точку и прошли проверку cryptography; изменение подписанных байтов
отвергалось. Получен публичный ключ, а не закрытый ключ Sony. Во время работы
запросы не восстанавливают и не устанавливают ключи. Исходные захваты и билеты
исключены из публичной сборки.

Поддерживаемый идентификатор подписанта: `4ca0c71d`.
Игровой сервис: `UP1005-BLUS30829_00`, наблюдавшийся у BLES01597 1.02 с NA Cloud.
Другим регионам/сервисам или смене ключа нужны новые подтверждения и явная
проверка конфигурации оператором. Произвольные service ID не принимаются.

Проверяются срок, время выдачи (допуск до пяти минут вперёд), идентификатор
аккаунта, подписанный профиль, сервис и ключ. Повтор параметра auth, неверные
Base64/DER, ненулевое заполнение подписи и изменённая подпись отвергаются.
В фиксированном поле подписи допустимо разное число завершающих нулей;
строгая DER-подпись проверяется по исходному подписанному префиксу.
Часы VPS должны быть верны. В кэше — до 2048 отпечатков проверенных билетов;
истечение срока учитывается и для кэша.

## Права ящиков

Подписанный аккаунт связывается с профилем при первом обращении. Он может
читать/изменять свои `TomeGift`, `TomeGiftJP` и `GameToWeb`, добавлять новую запись
`MAP_SET` в любой из двух почтовых документов другому адресату. Ответ содержит лишь отправленную запись,
а не чужой ящик. Иное значение под существующим ключом подарка отвергается;
идентичный повтор не создаёт вторую запись. Успех сообщается после фиксации базы.

Чужие чтение/удаление и замена ящика целиком запрещены. Непустой
`SET` с непустым значением для обоих почтовых документов запрещён при авторизации; пустая инициализация сохраняет подарки.
Биты friendship/world/friend через PSN не проверяются. Пакет должен иметь
допустимые размер, Base64 и маркер BOD. Полностью экипировку сервер не разбирает,
награды не создаёт. Результаты OFW: [STATUS.ru.md](STATUS.ru.md).

## Текущие ограничения ресурсов

| Ресурс | Ограничение |
| --- | --- |
| Принимаемые HTTPS-соединения | На IP 5/с, кратковременный запас 20; всего 40/с, запас 80 |
| Ожидающие HTTPS-обработчики | 32 на все слушатели, до 8 на IP; тайм-аут сокета 10 с |
| Публичное тело запроса | 64 КиБ; chunked не поддерживается |
| DNS-запросы | На IP 20/с, запас 60; всего 300/с, запас 600 |
| TCP-клиенты DNS | 32 на слушатель, до 4 на IP; ограничены запросы и простой |
| UDP-ответ DNS | 512 байт, затем TC и повтор через TCP |
| Подписанные изменения ящика | На аккаунт 1/с, запас 10; всего 20/с, запас 40 |
| Операции в пакете | 64 |
| Декодированный подарок | 32 байта–32 КиБ, наблюдавшийся маркер BOD |
| Значение / документ | 64 КиБ / 512 КиБ |
| Подарки в ящике | 128 |
| Данные документов / документы / владельцы | 64 МиБ суммарно / 20 000 / 20 000 |

Это значения по умолчанию, а не гарантия ёмкости. Ошибка квоты отменяет весь
пакет. Квота данных не включает весь размер SQLite, журналов и резервных копий.
Общий NAT нескольких консолей может упереться в ограничение одного IP.
Следите за нагрузкой/копиями и меняйте ограничения после проверки;
сетевые атаки на канал обрабатываются оператором и провайдером.

## DNS и проверки оператора

Публичный DNS допускает только IN A/AAAA в `playstation.net`, `playstation.com`,
`ndmdhs.com`, `thqconnect.com`. Точные настроенные имена THQ указывают на VPS,
остальные разрешённые запросы передаются дальше. Произвольные имена и
ANY/TXT/другие типы получают REFUSED. Это не общий домашний DNS.

Для игроков откройте UDP/TCP 53 и TCP 443/8443. Необязательный UDP/TCP 1053
нужен обходу проблемы маршрута и не вводится в обычных настройках PS3.
Из второй сети проверьте игровое A-перенаправление, PSN A, отказ чужому
имени/ANY, анонимный health 200 и почту без билета 403. Затем в игре проверьте
подписанные чтение/отправку и получение предмета адресатом.
Старое поле health `ofw_verified:false` не является проверкой игры в реальном
времени. Подтверждённые игроками OFW-пересылки/получение и сообщение о трофее,
с их границами, записаны в [STATUS.ru.md](STATUS.ru.md).
