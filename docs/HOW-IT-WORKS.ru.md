# Устройство сервера

PS3 OFW → DNS → HTTPS Cloud API → проверка PSN-билета → SQLite → ответ игре.

## Маршрутизация

DNS возвращает IPv4 сервера для настроенных имён THQ Connect. Cloud-узел:
`thqc-darksiders2-ps3-na.thqconnect.com:8443`. Разрешённые домены PSN
разрешаются через upstream DNS. Вход в PSN обслуживается Sony.
DNS определяет адрес назначения; маршрут задаётся шлюзом и VPN независимо.

## TLS

HTTPS завершается на сервере. Используется экспериментальная цепочка
с неизвестным алгоритмом подписи промежуточного звена. Принятие текущей
цепочки клиентом OFW/BLES01597 сообщено игроком. Внутренняя причина принятия
не установлена; новая цепочка и другие версии требуют отдельных проверок.
Сертификат для постороннего имени не становится подходящим от смены DNS.

## Авторизация

Игра получает PSN-билет через системные службы Sony и передаёт его
в Base64-параметре `auth`. Билет содержит подписанные профиль, идентификатор
аккаунта, сервис и время действия. Пароль PSN серверу не передаётся.

`psn_auth.py` проверяет формат, ECDSA-подпись закреплённым публичным ключом,
сервис, время выдачи и срок действия. Публичный ключ не позволяет выпускать
билеты. Проверка локальная; запрос к Sony для каждого письма не нужен.
Кэш содержит отпечатки и подтверждённые личности, срок билета учитывается.

При первом подтверждённом обращении профиль `/psn/name` связывается
с подписанным идентификатором аккаунта. Владелец читает/изменяет свой ящик.
Другой подписанный пользователь может добавить новый подарок, но не читать
или удалять чужую почту. Смена Online ID требует действий оператора.

## Подарки

Игра формирует пакет письма с вложением. `MAP_SET` передаёт профиль адресата,
ключ подарка и пакет. Сервер проверяет права, Base64/BOD, размер и квоты,
сохраняет пакет без изменений и записывает подписанного отправителя/время.
Успешный ответ возвращается после фиксации транзакции SQLite.

`MAP_GET` возвращает записи как `[ключ,[пакет,отправитель,время]]`.
Клиент загружает их в локальную почту и может удалить ключ из облака через
`MAP_REMOVE` до получения предмета в инвентарь. Предмет восстанавливает игра.
Один `MAP_REMOVE` или HTTP 200 не доказывает получение предмета.

Хранилище — `cloud.sqlite3`: `documents`, `map_metadata`, `profile_owners`.
Европейский ящик — `TomeGift`, японский — отдельный `TomeGiftJP`.
Автоматического переноса подарков между ними нет.
Идентичный повтор существующего ключа сохраняет запись; другое содержимое
под тем же ключом отвергается. Повтор после удаления ключа не считается
глобально предотвращённым дубликатом.

## Трофей и ограничения

Игра обрабатывает Pay It Forward после успешной отправки. Сервер не вызывает
API трофеев и не меняет сохранения. Получение предмета адресатом — отдельный шаг.

GDS, THQ/SSO, новости, проверка дружбы PSN и полная семантика предметов
не реализованы. Полные билеты и тела запросов в публичном режиме не пишутся;
журналы метаданных содержат IP и технические события. База и резервные копии
содержат данные игроков и хранятся приватно.
