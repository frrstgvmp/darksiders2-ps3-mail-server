# v0.4.6 — почтовый сервер PS3 OFW

Предварительный релиз исходников почтовой службы THQ Connect для Darksiders II PS3.

- Перенаправление настроенных имён THQ, DNS по UDP/TCP.
- Основной DNS `193.232.178.202`; дополнительный `1.1.1.1` — проверенная пользователем конфигурация.
- HTTPS Cloud API с проверкой подписи и срока PSN-билетов.
- Постоянные ящики SQLite, метаданные отправителей, атомарные пакеты операций.
- Чтение/удаление владельцем; авторизованное добавление другому; квоты и лимиты.
- Отдельный `TomeGiftJP`; проверка японской OFW ожидается.
- Установщик Debian/systemd, ежедневные копии, документация на двух языках.
