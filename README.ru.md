# Почтовый сервер Darksiders II для PS3

[English](README.md)

Собственный сервер почты THQ Connect для Darksiders II на PS3 OFW.
Перенаправление DNS, проверка подписанных PSN-билетов, хранение подарков.

## Статус

OFW/BLES01597: игрок сообщил об открытии почты, отправке подарков, получении
предметов в инвентарь и Pay It Forward 14–15 октября 2026 года. Точный номер
прошивки и версия обновления игры не записаны. Другие издания требуют
отдельной проверки на OFW. [Совместимость](docs/COMPATIBILITY.ru.md).

Сервер хранит сформированные игрой пакеты подарков без изменений.
Сохранения не редактируются. Обработка трофея выполняется самой игрой.

## Подключение

1. Укажите основной DNS PS3: **193.232.178.202**. Дополнительный может быть **1.1.1.1**; работа этой комбинации подтверждена пользователем.
2. Сохраните рабочий шлюз. Отключите ненужный сетевой прокси.
3. Войдите в PSN и перезапустите Darksiders II.
4. Откройте сетевую почту. Оба участника должны использовать этот сервер.

Для описанной конфигурации OFW замена исполняемого файла игры и установка
сертификата на консоль не требуются. Адрес предоставлен оператором и может
измениться. [Инструкция игрокам](docs/PLAYER-GUIDE.ru.md).

## Реализация

| Компонент | Поведение |
| --- | --- |
| DNS | UDP/TCP; перенаправление настроенных имён THQ, разрешение разрешённых доменов PSN |
| HTTPS | Cloud API на порту 8443; экспериментальная цепочка сертификатов |
| Авторизация | Проверка подписи PSN-билета, сервиса, личности и срока |
| Хранилище | SQLite; атомарные пакеты операций, фиксация до успешного ответа |
| Подарки | Владелец читает/удаляет; другой авторизованный игрок добавляет новую запись |
| Операции | GET, SET, REMOVE, MAP_GET, MAP_SET, MAP_REMOVE, SET_PERM |

GDS, аккаунт THQ/SSO и новости не реализованы. Дружба PSN и полная семантика
предметов не проверяются. Японский `TomeGiftJP` реализован как отдельный ящик;
японская OFW и межрегиональная пересылка не проверены.

## Развёртывание

Debian 13, Python 3.10+, systemd, публичный IPv4 и `python3-cryptography`.
Порты: UDP/TCP 53, TCP 443/8443. [Установка](docs/INSTALL.ru.md).

Используется экспериментальная цепочка с неизвестным алгоритмом подписи
промежуточного звена. Она не является общедоверенной. Новая цепочка требует
проверки клиентом OFW; совместимость со всеми прошивками не установлена.
Релиз содержит публичный корневой сертификат и генератор. Рабочие закрытые
ключи, базы игроков и игровые файлы в релиз не входят.

## Проверки

```bash
sudo apt-get install python3-cryptography
python3 -m unittest discover -s tests -v
```

Для кандидата релиза прошли 33 автотеста: подписи билетов, права, квоты,
японский ящик, хранение, параллельные записи, DNS, маршрутизация и скрытие
чувствительных параметров. Локальные TLS-тесты проверяют API и не подтверждают
совместимость OFW.
