# Безопасность и приватность

[English](SECURITY.md) · **Русский** · [Главная](README.ru.md)

Публичный режим — экспериментальная почтовая служба с авторизацией.
Ограничения снижают риск злоупотреблений, но не заменяют независимый аудит
и не означают неограниченной ёмкости.

- `public_mode:true` принимает все IPv4 и всегда требует криптографической
  проверки PSN-билета для почты. Health/DNS билета не требуют. Закрытый режим
  использует `allowed_clients`; включайте `verify_psn_tickets:true` для авторизации.
- Закреплённый публичный ключ загружается из файлов оператора. Запрос не может
  передать или заменить его. Проверяются подпись, сервис/ключ, профиль/аккаунт,
  время выдачи и срок. Билет даёт доступ предъявителю: украденный действующий
  билет можно повторно использовать до истечения срока. В ограниченном кэше
  только отпечатки и подтверждённые личности; сырые билеты не хранятся.
- Подписанный пользователь читает/изменяет свой профиль и добавляет подарки
  другому. Чужое чтение/удаление, перезапись подарка и конфликт владения
  аккаунтом/профилем запрещены. Дружба и старые биты world/friend не проверяются.
  Проверка оболочки подарка не подтверждает полную семантику предмета.
  Не заявляйте защиту от любых читов или спама.
- Публичный DNS принимает только IN A/AAAA для `playstation.net`, `playstation.com`,
  `ndmdhs.com`, `thqconnect.com`. Другие зоны/типы отвергаются; перенаправляются
  только точные настроенные игровые имена. Частота DNS/HTTPS, рабочие потоки TLS
  и хранилище ограничены; см. [лимиты](docs/PUBLIC-SERVER.ru.md). Сетевые атаки
  на доступность требуют действий оператора/провайдера.
- Экспериментальная TLS-цепочка не проходит обычную проверку. Не используйте
  её в других сервисах. Принятие ограничено описанной
  конфигурацией OFW/игры; другие установки требуют проверки.
- Сырые захваты в публичном режиме запрещены. Параметры auth/email/profile/key/value
  скрываются. В метаданных остаются IP и имена конечных точек. Ротация файлов
  и срок хранения systemd journal настраиваются отдельно.
- SQLite и копии содержат связи профилей/аккаунтов и непрозрачные пакеты
  подарков/статистики. Храните приватно, ограничивайте доступ, задавайте срок
  хранения и удаляйте данные по запросу через оператора. Веб-аккаунтов игроков
  и автоматического портала удаления нет.
- Не включайте в Git пароли, рабочие конфигурации, закрытые ключи и захваты.
  Граница релиза — явный список экспортёра; одного `.gitignore` недостаточно.

Сообщайте об уязвимостях приватно через механизм security reporting репозитория,
если он включён, иначе — лично оператору. Не прикладывайте билеты, ключи,
базы игроков и исполняемые файлы игры.

При раскрытии закрытого серверного ключа создайте новые материалы, проверьте
приём клиентом и перезапустите с заменой. Пароли VPS меняйте интерактивно,
не сохраняйте в коммитах. Замена TLS-ключа не меняет закреплённый публичный
ключ проверки билетов Sony.
