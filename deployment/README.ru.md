# Развёртывание

[English](README.md) · **Русский**

Среда: Debian 13, Python 3.10+, systemd, публичный IPv4.
Зависимость: `python3-cryptography`.

[Установка](../docs/INSTALL.ru.md): сборка приватного комплекта, порты,
systemd, обновление, резервные копии и диагностика.

- `install.sh`: установка подготовленного приватного комплекта от root.
- `export_vps_bundle.py`: комплект кода, приватных TLS-файлов и необязательного снимка базы.
- `export_public_source.py`: экспорт явного списка публичных исходников.
- `config.public.example.json`: публичный доступ с обязательной авторизацией PSN.
- `config.example.json`: ограничение IP с авторизацией PSN.

Приватный комплект и архив публичных исходников — отдельные результаты сборки.
Для GitHub предназначен только архив публичных исходников.
