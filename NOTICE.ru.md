# Происхождение материалов и сторонние права

[English](NOTICE) · **Русский** · [Главная](README.ru.md)

Лицензия MIT применяется к исходному коду и документации самого проекта.

`assets/thq-connect-root.pem` — публичный сертификат THQ Connect Root CA,
извлечённый из оригинального клиента Darksiders II PS3 1.02 для совместимости.
SHA-256 сертификата в DER:
`d86d20e06db3f01be90bb7743c1e799e776e12a09023ca5d327df8b94bf35029`.
Закрытый ключ THQ CA не включён и не известен. Проект не заявляет владения
этим сторонним сертификатом или распространения его по MIT.

Названия Darksiders, THQ и PlayStation используются для обозначения совместимых
игры и платформы. Независимый проект не одобрен владельцами этих названий.

`assets/psn-darksiders2-key.json` содержит публичную точку ECDSA для проверки
наблюдавшихся PSN-билетов Darksiders II, идентификатор `4ca0c71d`.
Она восстановлена офлайн по трём независимо выданным подписанным билетам
оператора. Закрытый ключ Sony не включён и не получен. Закреплённый публичный
ключ используется только для проверки билетов.

`psn_auth.py` — независимая реализация Python опубликованного формата TLV
и подписи NP-билетов. Источники формата:

- [Документация ProjectLighthouse](https://github.com/LBPUnion/ProjectLighthouse/blob/main/Documentation/Tickets.md).
- [Обсуждение формата и подписи](https://github.com/LBPUnion/ProjectLighthouse/pull/600).

Реализация LittleBigRefresh/NPTicket изучалась как справочник формата.
Сторонняя реализация или исходники AGPL не скопированы и не включены в релиз.
Владение ключом проверки Sony и его лицензирование по MIT не заявляются.
